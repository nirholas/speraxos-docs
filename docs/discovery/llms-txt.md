# llms.txt

[`/llms.txt`](https://chat.sperax.io/llms.txt) is a concise, LLM-oriented index of the product. [`/llms-full.txt`](https://chat.sperax.io/llms-full.txt) is the long form. [`/capabilities.json`](https://chat.sperax.io/capabilities.json) and [`/tools.json`](https://chat.sperax.io/tools.json) list capabilities and tools as JSON.

```bash
curl -s https://chat.sperax.io/llms.txt | head -40
```
