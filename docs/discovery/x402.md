# x402

`/.well-known/x402` returns JSON with `version` and a `resources` array of paid endpoints under `/api/x402/`. Fetch one:

```bash
curl -s https://chat.sperax.io/.well-known/x402 | jq '.resources[:3]'
```

Request a resource without payment to see the x402 challenge:

```bash
curl -i https://chat.sperax.io/api/x402/fear-greed
```

The OpenAPI 3.1 document at [`/openapi.json`](https://chat.sperax.io/openapi.json) describes the same paths (for example `/api/x402/markets`, `/api/x402/yields`).
